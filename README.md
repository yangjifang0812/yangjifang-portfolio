# 杨季芳｜Marketing Portfolio

Responsive personal marketing portfolio built from the uploaded PPT portfolio.

## Structure
- `index.html` — page structure and project content
- `styles.css` — responsive visual system
- `script.js` — case modal, animations, progress bar
- `slides/` — rendered case-study visuals from the original deck

## Deploy with GitHub Pages
1. Create a new public GitHub repository, e.g. `yangjifang-portfolio`.
2. Upload all files in this folder to the repository root.
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`.
4. The public site will be available at the GitHub Pages URL shown by GitHub.
